# 小红书真实话题自动选择

当前版本：matrix-cloud:20260916-native-topics-v1。云端和本机连接器的执行脚本均已更新。

## 改动

原逻辑直接粘贴井号文本，无法代表平台话题。现在先写正文，再逐个使用浏览器原生输入输入井号和标签；等待同名候选，按候选实际位置点击，核对编辑器 `data-topic` 中的话题 ID 和链接。候选选择严格限制在平台话题列表，不点击正文、推荐按钮或近似名称。

未找到同名话题、网络超时或点击未形成原生话题节点时保留编辑页并报告阻塞，不把普通文本报告为话题成功。可修改标签或人工处理。不会自动正式发布。

保存后验证平台本地草稿的 `hashTag` 话题 ID/链接、带 `[话题]#` 的正文序列化、图片文件编号及草稿箱唯一条目。兼容当前平台自动保存，以及保存后暂时停留在编辑页的情况；仅在持久化内容核对成功后打开草稿列表。
