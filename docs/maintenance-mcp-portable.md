# 维护 MCP 接入

维护 MCP 通过独立 HTTPS 入口提供项目摘要、源码读取、隔离修改、测试、发布准备、部署、回滚和清理工具。使用 OAuth/PKCE、权限范围、可撤销凭证和逐次确认。

接入步骤：

1. 管理员在维护服务创建最小权限凭证。
2. 在 Codex 或 GPT-6 系列客户端添加维护 MCP 地址，并完成 OAuth/PKCE。
3. 先使用只读能力检查项目摘要、提交和测试状态。
4. 修改必须进入隔离工作区；检查通过后由管理员确认具体提交和镜像摘要。
5. 新修改会使旧确认失效；发布失败可回滚到最近验证通过版本。

维护服务不暴露任意 shell，不将生产密钥挂载到测试环境，也不把 Token、Cookie 或浏览器 Profile 写入日志。客户端是否允许写入取决于其权限配置，模型名称本身不代表拥有部署权限。
