# Playwright 采集与本地媒体 Implementation Plan

**Goal:** 在现有同步按钮下，以账号独立会话采集真实内容，保存媒体并显示证据及缺失原因。
**Architecture:** Express/SQLite/React 保留；独立 Playwright collector 通过本机连接器获得 CDP 端口；Python requests worker 下载媒体。草稿上传执行器不修改。
**Tech Stack:** Node.js, playwright-core, Python requests, Express, SQLite。
**Spec:** 用户 2026-09-11 确认的方案及本任务对话。

## 约束
- 只读小红书内容，不发送私信、不发表评论、不发布。
- 同账号共用现有 Profile 锁，身份核验后才能保存；其他账号数据不入库。
- 不把公共推荐、空页面、封面或未解析响应当成完整采集结果。
- 媒体保存于工作区内账号ID/日期/媒体类型/笔记ID目录，私有 API 按工作区及账号授权。
- 登录失效保留可见登录页，状态明确提示；不声称永久登录。

## 执行步骤
- [ ] 建立 Playwright 真实页面探针，验证登录、网络响应格式、笔记列表、详情和消息入口。
- [ ] 先测试响应结束读取、账号范围约束、正文图片顺序、错误不被忽略；实现采集模块。
- [ ] 先测试下载路径隔离、失败不留假文件、重复下载缓存；实现 Python 下载器与 Node 调用桥。
- [ ] 测试私有媒体接口和 Range 请求、跨账号与工作区拒绝；接入数据库和 React 媒体渲染。
- [ ] 接入同步任务阶段、持久化进度与重复点击去重；保留现有草稿模块。
- [ ] 运行全量测试和构建，重启服务，用真实账号同步并保存脱敏证据，记录仍未通过项。
