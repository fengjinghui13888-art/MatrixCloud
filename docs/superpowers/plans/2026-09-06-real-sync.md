# Real snapshot ingestion implementation plan

> **For agentic workers:** Use superpowers:executing-plans task by task.

**Goal:** Store verified note fields without fabricating missing metrics or links.

**Architecture:** Existing authenticated HTTP and fixed WorkBuddy MCP share the same SQLite store. Nullable note fields represent unknown values. Existing confirmed values survive partial resync.

**Tech Stack:** TypeScript, Express, Zod, SQLite, React, Vitest.

**Spec:** User-approved chat design: fixed WorkBuddy MCP; independent customer-selected model provider; no fabricated data.

## Constraints

- No publishing or privacy changes on Xiaohongshu.
- No model credentials reused or charges incurred.
- Model execution and multi-tenant isolation remain a separate deliverable.
- Workspace is not a Git repository; no commits or worktree operations.
