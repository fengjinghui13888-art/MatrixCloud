# 矩阵云客户交付范围

客户使用同一个 HTTPS 线上工作台，自行注册、登录；换电脑后以同一账号进入同一工作区。公开注册始终创建独立工作区，首次平台初始化只允许服务器本机 setup。已有用户、密码、工作区与模型费用配置保持兼容。注册密码至少12字符、UTF-8最多72字节；旧密码仍可登录。连接请求超时必须显示可重试错误。

电脑连接器按 Windows x64、ARM64、x86，macOS Intel、Apple 芯片，Linux x64、ARM64分别出包。包内提供校验过的 Node22.14.0、必要纯JavaScript依赖、完整运行脚本、固定HTTPS入口和客户操作说明，不含任何管理员密钥、云设备凭据、客户数据或浏览器登录状态。客户完整解压即可启动，首次通过自己的账号授权电脑。操作小红书须在执行电脑安装可识别的Chrome、Edge或Linux Chromium并正常登录。

Windows x64本机实际验收；其他架构和操作系统分别标为待实机验证。Mac正式包必须经macOS codesign校验，Windows构建的Mac候选不能伪称正式签名通过。官网只发布验收通过的包，候选存放独立目录。运行时基础范围依据Node22官方平台文档，不宣称覆盖所有旧系统。

开发维护交付包必须包含本次未提交修复源文件，准确记录git基线、工作区是否有修改、每文件SHA256；不夹带生产密钥和数据。真正上线必须取得可用的维护连接，并验证部署后的公网注册、登录、租户隔离及连接器下载。当前服务器SSH无法连接，不能把本地修复和候选包称为已上线。
