# 商业交付执行大纲（持续累加）

更新：2026-09-15。本文区分实际现状、已验证功能和后续验收要求；源码完成不等于公网验收通过。

## 交付目标

客户使用一个 HTTPS 工作台，安装 Windows/macOS 连接器后输入一次性码即可绑定电脑。账号扫码、内容读取、图文生成、人工审核、保存账号草稿、素材归档、线索跟进形成完整闭环。平台发布必须由人确认，禁止把“已下发”显示成“已同步”。

## 当前事实

- 前端 React/TypeScript/Vite；服务端 Express/Node.js；连接器 Node.js + Chrome 独立 Profile + Playwright/CDP。
- 当前云端使用 PostgreSQL 16，schema 2：业务数据按实体分表，租户记录携带 tenant_id，并实施复合外键和行级隔离。旧 SQLite 只保留为迁移前快照，禁止回写覆盖生产库。
- 图片/视频当前归档在服务器持久化目录；COS 尚未完成接入。本地连接器保存浏览器状态和执行缓存，不能宣称客户本地 SQLite 素材库已经实现。
- 新增与重设密码使用 bcrypt（cost 12）；旧 scrypt 密码及会话已保留，下次正确登录后迁移。bcrypt 密码限制为 72 字节，防止截断；已有超长 scrypt 密码继续按原算法验证。
- 既有双账号同步、真实平台浏览器草稿有验证证据，位于 outputs/studio-verification。网页版草稿在该账号执行浏览器内，不自动出现在手机或另一台电脑。
- 客户配对与主动 WebSocket 任务通道已在实际双账号中验证：按 workspace/device/profile 绑定；保留现有 owner 连接作为迁移回退。当前传输实现单响应上限 64 MB，超大视频必须走后续对象存储分片上传。

## 一、先跑通一位客户

1. HTTPS 证书签发、自动续期和到期监控；保留现有登录账号和持久化数据。
2. 5 分钟一次性配对码；云端仅存码和设备令牌哈希；本机凭证限制文件权限；撤销立即拒绝后续请求。
3. 客户端主动 WSS 连接，无需客户开端口或配置 SSH；任务只允许账号登录/状态、同步、审核后草稿操作。
4. 明确绑定客户、设备、账号会话。新客户不得回退使用平台所有者电脑；离线不能偷偷换设备。
5. 两个客户之间代码、设备、账号、任务和回执不能互访；重启/过期/撤销/重复点击/断网均有验收。
6. 实机完成登录→配对→账号内容读取→已有内容审核→草稿保存→证据核验，不额外收费生成、不对外发布。
7. Windows/macOS 安装器：内置运行时、Chrome 检测、配对窗口、自启动、版本升级/回滚、卸载保留数据选项。源代码压缩包不能代替客户安装器；签名和公证须具备实际开发者凭证后验收。

## 二、数据库和租户权限

- tenant、user、xiaohongshu_account、message、clue、model_config，以及 asset、template、generation、job、job_attempt、device、audit_log。
- 所有租户拥有的记录必须带 tenant_id；主键/唯一约束/外键含租户边界，服务端从登录身份取 tenant_id，不信任客户端传值。
- 每个客户可以多个操作员，管理员/运营/仅看线索角色；租户禁用、账号失效和封禁分别处理。
- Cookie 优先保留客户浏览器；需要集中保存时使用 AES-GCM 认证加密。API 密钥加密，前端只收到脱敏值。密钥与数据备份分开保管并设计轮换。
- 已选 PostgreSQL 16，自建于当前服务器独立容器，不是 MySQL，也不是托管数据库。已完成逐集合迁移哈希核对、重跑不覆盖、pg_dump 恢复演练；需要托管高可用时另行迁移。
- 应用数据库账号仅业务所需权限；3306/5432 不开放公网；按 tenant_id/account_id/created_at 建复合索引。
- 任务领取短事务、租约、幂等键、失败重试；调用模型/浏览器时不持有数据库锁。禁止多实例继续写整份 JSON。

## 三、素材和模板库

- 原图、视频、二创结果上传腾讯云 COS 私有桶；业务表保存对象 key、类型、大小、SHA256、租户和来源关系。下载使用短时签名链接。
- 客户电脑自动初始化 SQLite 缓存、待上传队列和任务回执；云端是业务主数据，本地是缓存及重试队列，定义冲突处理和删改同步。
- 批量上传历史素材，建立标签、模板、版本和授权范围；文案生成、生图配置分开保存并显示当前使用模型。
- 图生图只对实际支持的厂商开放参考图/强度选项。0.55–0.7 不是通用相似度保证，不同模型参数意义/方向可能不同；提供预览、版本对比、人工选择。
- 二创结果自动回流素材库，保存原素材、模型版本、参数、生成记录与发布草稿的关系。

## 四、删除、备份、升级、迁移

- 账号、同步内容、生成内容、线索、素材均支持单删/批删；先展示影响范围，处理在途任务和引用；删除线索后来源应恢复可创建状态。
- 元数据软删保留恢复窗口；对象文件只有在无引用并经过保留期后物理删除；本地缓存接收删除标记。
- 每日加密备份，异地存放，保留 7–30 天；上线前实际恢复一次。数据库、对象清单、配置和加密密钥分别可恢复。
- 每次部署备份、迁移检查、健康检查、失败自动回滚；实例更新不覆盖持久化数据。
- 迁移包包含程序版本、配置模板、数据库备份、素材清单、连接器版本、恢复和重新配对步骤。浏览器登录态不承诺任意跨电脑直接复制有效。
- 审计记录登录、权限、模型配置、同步、删除、草稿回执；日志不得记录 Cookie/密钥/配对码全文。

## 五、容量和成本

容量由同时在线操作员、活跃账号数、同步频率、素材增量、并发模型调用决定，不能只用“客户数量”估计。

试运营起点：云端 API 4 核 8 GB、SSD 100 GB（数据库/日志/临时文件），图片视频移入 COS；外部模型 API 不需要自购 GPU。该配置是压测起点，不是容量承诺。正式多客户使用至少拆分数据库与应用，按任务积压和延迟扩容 worker。

指标：登录/列表 P95、同步排队时长、任务失败率、数据库写延迟、CPU/内存、COS 存储及流量、每租户模型预算。先模拟 10/50/100 个活跃客户和明确账号频率测容量，再确定规格。未经验证不承诺支持数千客户。
