# 本地手动启动

## 每次使用

1. 双击桌面“启动矩阵云”。数据库、后端和前端自动检查并启动；浏览器打开 http://127.0.0.1:5173/ 。
2. 需要小红书扫码、同步或保存草稿时，再双击桌面“启动连接器”。保持客户端运行。
3. 关闭启动命令窗口或网页不会停止后台服务。重复双击启动入口会复用服务。

这些入口不会安装开机自启动任务。重启电脑后仍需要手动双击。连接器原有自启动选项由客户端配置控制。

## 停止与故障

双击 backend/STOP-LOCAL.bat，停止此入口管理的前端和后端。请先等待同步、生成和草稿任务结束。数据库及连接器不会随此前后端停止。

服务意外退出时，后台守护进程会重新启动对应服务。若数据库配置、依赖或端口被其他程序占用，启动器会提示失败，不会擅自结束其他进程。

日志位于 backend/data/local-workbench/services.log 和 supervisor.log。不要删除 backend/data、数据库文件、.env、Python 环境和客户登录目录。

## 修改代码之后

本地日常入口使用 frontend/dist 中的构建文件。修改前端源码后先在 frontend 执行 npm run build。修改后端源码后，等待业务任务结束，再停止并重新启动本地服务。

开发调试仍可使用 python run.py all --no-open，但需先停止日常后台服务，避免重复占用端口。此开发命令依旧随终端关闭而停止。

## 管理后台

同一服务的后台入口是 http://127.0.0.1:5173/admin.html ，需要独立管理员账号登录。桌面客户端只打开客户工作台，不授予管理员权限。
