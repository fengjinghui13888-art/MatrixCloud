# 矩阵云独立平台管理后台

## 入口与登录

- 客户工作台：`http://127.0.0.1:5173/`
- 平台管理后台：`http://127.0.0.1:5173/admin.html`
- 管理员账号：`matrix-admin`。本机登录信息单独存放在 `backend/data/recovery/platform-admin-login-20261015.json`；不要上传该文件或放进源码包。

平台管理员与客户账号分开。后台使用自己的 HttpOnly / SameSite 严格会话 Cookie，路径 `/api/platform-admin`，不借用客户登录 Cookie。普通客户及其团队管理员不能访问平台后台；仅凭后端服务令牌也不能登录此管理界面。管理员登录与客户工作台登录互不替换。

## 功能

1. **平台概览**：客户工作区、启用中的客户、接入的小红书账号数与在线设备数；不把平台自身工作区计入客户统计。列表包含当前数据库中已有的历史验收工作区，并不等同于付费客户数。
2. **客户管理**：按工作区名称/登录账号搜索，按状态筛选；查看客户成员、权限及业务记录数量。不会展示客户密码、模型密钥、浏览器登录凭证。
3. **停用/恢复客户**：停用时该客户成员旧会话撤销，数据保留；恢复后成员重新登录。平台所属工作区不能停用。操作前有确认，结果写入审计。
4. **协助找回密码**：在客户详情选择成员，签发 15 分钟一次性恢复码。核实归属后通过私密渠道交给本人，客户在工作台“忘记密码”自行设置新密码。重新签发会使上一次未使用的码作废；切换页面或退出后不再展示恢复码。
5. **连接设备**：查看设备所属客户、系统、版本、在线/离线/撤销状态与最近连接时间。
6. **操作日志**：平台管理员最近 100 条登录、客户停用/恢复、恢复码签发记录；后台不显示密码或密钥。

## 技术与目录

与 AI 自动获客系统统一：React + TypeScript + Vite，Python + FastAPI，PostgreSQL。管理后台没有另起 Node 服务，也没有增加生产数据库。

```text
frontend/
  index.html               客户入口
  admin.html               管理员入口
  admin/                   独立管理界面
  src/styles/product-tokens.css  共用产品配色/圆角变量
backend/
  app/platform_admin.py    平台管理接口
  app/auth.py              统一认证与权限校验
  app/recovery.py          一次性密码恢复
  tools/bootstrap_admin.py 仅服务器本机初始化管理员
```

主目录继续只有 frontend/backend 两个业务文件夹。管理端与客户工作台共用颜色/圆角变量：灰蓝背景、白色卡片、黑色主按钮。管理端独立打包入口，客户入口不加载管理页面代码。

## 启动与部署

沿用现有 PostgreSQL、后端、前端启动流程，不需要多启动一个管理服务。`pnpm build` 同时输出 `dist/index.html` 和 `dist/admin.html`。生产环境部署完整 dist，反向代理 `/api` 到现有 FastAPI，并使用 HTTPS、正确的 PUBLIC_ORIGIN 和持久化 PostgreSQL；不要只上传 index.html。

新环境尚无平台管理员时，在 backend 中执行：

```powershell
.venv\Scripts\python.exe tools/bootstrap_admin.py --username matrix-admin --output data/recovery/管理员登录信息.json
```

Mac/Linux 使用 `.venv/bin/python`。输出目录必须已存在，输出文件必须未使用。工具生成随机密码，只写入本机文件，并记录 `data/work/grey/platform-owner` 标识；创建后重启后端。已经存在平台管理员时工具拒绝再次初始化，防止覆盖或抢占账号。

忘记管理员密码时由服务器负责人使用 `tools/password_recovery.py` 签发恢复码，不能重新初始化或修改数据库明文密码。客户页的找回流程也适用于平台管理员设置新密码，之后仍回独立管理入口登录。

源码包不带登录凭据、数据目录和签名私钥。原私有数据 ZIP 仍是历史快照，不包含本次新建的平台管理员；迁移新环境时应恢复适当的最新 PostgreSQL 备份及私有配置，或按流程初始化管理员。
