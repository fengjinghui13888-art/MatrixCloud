# 对抗测试与清理报告 · 2026-10-13

结论：当前 Python 后端 / MCP / 连接器与 React 前端通过下列验证，可以本机正常启动。检查中发现的问题已修复；这不等同于所有真实供应商和平台流程都已验收。

## 发现并修复

1. 导入接口缺少旧版本完整结构校验。缺失账号字段、错误 metrics 类型、负数/布尔计数和非法媒体 URL 可导致坏数据入库或后续同步 500。新增 app/snapshots.py，在 HTTP、MCP、连接器同步三个入口写入前统一校验；保留部分快照合并语义，拒绝非法端口。9 个参数化回归通过，正常连接器产物兼容。
2. 登录启动的迟到回执可能复活已取消的扫码任务。现在成功和异常回执均重新读取持久状态，仅 starting 状态能更新。
3. 迟到模型结果可能覆盖生成取消状态。现在只允许当前生成版本记录失败；生成 worker 按工作区和任务 ID 管理，取消未执行平台操作的生成不依赖设备绑定。取消本地 worker 不代表供应商端已撤销在途计费请求。
4. 补齐 frontend/public/favicon.svg，消除页面图标 404。
