# 图片预览、创作排版与草稿保存验收

## 四项修复

1. 生成图片新增点击放大预览。支持关闭、左右切换、Esc、键盘焦点限制和关闭后返回原控件；预览原有图片，不重新生成或修改素材。
2. 文案和图片区等高 460px、顶部对齐，图片区列宽大于文案区。单图展示高度 350px；长正文在固定文本框内部滚动，图片区独立滚动。桌面任务列表与编辑器高度 760px，窄屏改为上下布局。图片数量、尺寸选择和原素材保持。
3. 人设细化为活动主理人、AI 实践分享者、产品测评者、门店经营者、知识讲解者、生活记录者，每个模板写明受众、具体信息重点与不可编造内容。文案风格提供报名攻略、步骤干货、对比测评、朋友分享、避坑清单，并把完整结构要求送入生成。自定义说明保留，小红书基础风格仍由后端统一约束。
4. “待审核”任务原来直接发送 dispatch，但后端只接受 approved / filled，因此在执行电脑启动之前被拒绝。现在提交当前 revision，先验证版本、完整图片和目标设备，再原子批准并启动。旧版本内容不能被无意批准；重复点击和已完成任务仍保留防重复处理。

## 实测发现的第二处问题

接口修复后，原账号的 Chrome 已关闭，保存任务连接旧 CDP 端口失败。失败发生在上传之前，连接器返回安全重试标记。修复 BrowserRuntime：仅在 TCP 连接已断开时重新打开同一个 profile，复用登录目录，并准备创作后台和网页版以核对身份。浏览器身份变化、平台要求验证及上传结果不确定时仍停止，不自动绕过或重复上传。
