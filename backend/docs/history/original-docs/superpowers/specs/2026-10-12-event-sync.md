# 小红书事件同步

用户已授权执行，最新指令要求后台识别新东西后同步，取消每3分钟定时采集。

连接器只观察已经存在的专属小红书浏览器会话，不读普通Chrome Cookie，不主动刷新小红书。允许生命周期重连与有事件后的等待重试，不允许无事件的平台轮询。网络响应中的新笔记、评论、私信标识和可辨识通知变化产生更新提示；提示不等于已确认新数据，实际入库后才显示新增数量。

设备通过现有授权WebSocket发送严格结构的事件提示（eventId/profile/kind/fingerprint），云端验证客户、设备、绑定和账号；落盘后确认接收，合并同账号事件，仅在原设备在线、登录身份匹配、账号无未确认任务时启动增量同步。任务自身产生的浏览器流量不得触发反馈循环。离线事件重连后再发送，撤销授权不得继续发送。固定定时器只能管理连接生命周期、合并事件、传输重试和读取已入库快照，不能发起无事件采集。

新增采集模式incremental复用原profile、队列和保护。笔记沿用已有详情补全；评论、会话和私信历史遇已知标识截止，并限制浏览页数。媒体缓存、账号身份双重校验、unknown-stop保护、平台限制暂停全部保留。完整人工同步仍可执行。

工作台显示事件同步状态与最近发现事件/同步时间，后台结果刷新后显示真实新增内容、评论、消息数量。可关闭自动同步。浏览器窗口必须存活且页面会收到事件；平台无推送、标签被休眠时不保证即时发现。真实平台验收单独记录。

不修改模型、费用、生图数量、素材库、登录凭据和云安全设置。
