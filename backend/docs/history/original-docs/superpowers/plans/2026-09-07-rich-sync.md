# Rich content ingestion implementation plan

> **For agentic workers:** Execute inline with test-driven-development. No delegation or git operations in this non-git workspace.

**Goal:** Preserve and render actual full media and messages returned by the user's collector without substituting covers for video.

**Architecture:** Extend the existing authenticated snapshot contract and SQLite store. Optional fields preserve existing snapshots. Direct messages are account-scoped and never enter public templates. Source collection is a separate dependency, not implied by successful ingestion.

**Tech Stack:** TypeScript, React, Express, Zod, SQLite, Vitest.

**Spec:** User-approved chat scope, 2026-09-07: Yingdao deterministic collection preferred; full content required; request help for missing workflow access.

## Global constraints

- No fabricated live data, no public posting, no LLM calls for deterministic importing.
- Only the user's authorized accounts and visible data. Stop for login/challenge; never bypass it.
- Missing media, comments or messages remain explicitly unknown, not complete.
- Existing auth is a single-workspace deployment; do not claim tenant isolation.
