## 从客户需求推导的约束

1. 账号归属必须有两个平台的明确身份依据。普通客户提交的数据不能成为浏览器会话授权依据。
2. 轮询只观察状态，不能反复刷新登录页或抢占焦点。未知状态不能解释为登录成功或数据为零。
3. 取消、删除、过期和已完成都是终态；晚到的请求不能逆转用户操作。
4. 升级更换代码时，运行配置、客户数据和恢复能力必须保留。一次手写的容器启动命令不能充当可重复的交付流程。
