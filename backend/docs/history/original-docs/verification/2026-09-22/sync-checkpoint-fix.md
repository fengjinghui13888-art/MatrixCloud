# 首次同步检查点修复与线上验收（2026-09-22）

## 根因

新账号完成登录绑定后，`lastSyncedAt` 为空，表示账号尚未完成过同步。首次同步的检查点会携带这个空值提交到 `/api/import`，旧校验只接受 ISO 日期，因此同步在保存内容前返回了 `Invalid ISO datetime`。

## 修复

- 接受空的 `lastSyncedAt`，只把它解释为“尚未同步”；非空非法日期仍拒绝。
- 客户端显示“尚未同步”，不显示原始校验结构或字段名。
- 导入校验失败时返回客户可理解的提示，不把 Zod、路径和内部字段泄露到页面。
- 发布中心在账号列表短暂尚未加载时保留操作入口，由服务端做最终账号和连接状态校验；账号列表存在时仍只向全部已连接账号派发独立任务。
