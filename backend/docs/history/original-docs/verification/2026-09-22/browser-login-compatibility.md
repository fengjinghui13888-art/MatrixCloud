# 浏览器登录与连接器兼容性验证（2026-09-22）

## 本轮行为

- 工作台不再复制或轮询展示二维码。点击“打开浏览器并添加账号/连接账号”后，所选执行电脑的连接器打开可见的 Chrome 或 Edge 小红书登录窗口，客户直接在该窗口扫码。
- 创作平台完成登录后，连接器只在进入网页版登录阶段首次将小红书标签页置前，不会每次状态轮询都抢回焦点。
- 工作台可由 Safari、Chrome、Edge、Firefox 打开；执行自动化使用 Chrome/Edge 的独立浏览器配置，以保留登录状态和草稿。
- 同一台电脑重复打开启动或配对入口时，后续启动会把操作转交给已运行的连接器，继续使用原浏览器配置和本机凭证，不再出现“进程已完成”后配对没有生效的情况。
- 同步状态文件改为原子替换并带短暂重试；即使执行电脑在结束任务时发生并发写入，客户页面也只显示可操作的同步提示，不会显示 JSON 解析细节。
- Safari 私密浏览或受管控配置禁止 `sessionStorage` 时，授权仍由服务器和连接器心跳完成；配对完成页带回账号矩阵入口。
- 本地授权仍要求精确云端来源；Safari 缺失 `Origin` 时仅接受精确匹配云端 `Referer`，其他来源继续拒绝。
