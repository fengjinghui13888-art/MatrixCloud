# 团队快速上手

工作台：https://47.106.94.169/ 。本次协议 4 版本和三种电脑安装包已上线；客户团队交付前，仍需按本文末尾清单完成对应电脑的实机验收。

## 管理员准备一次

在“设置 → 团队成员”给每位同事创建独立登录账号。日常操作选“运营”，只查看线索选“仅看线索”。将工作台地址和各自的登录信息分别交给成员。同一团队共享业务数据，各成员浏览器分别选择自己的执行电脑。

## 每位成员首次使用

1. 登录工作台，在连接电脑区域下载自己的 Windows、Mac Apple 芯片或 Mac Intel 安装包。
2. 将 ZIP 完整解压到一个固定目录，打开其中的启动文件。系统首次运行许可须由电脑使用者确认；如被系统拦截，请联系管理员，不要关闭电脑的安全保护。
3. 启动后会打开工作台。使用自己的团队账号登录，点击“授权连接这台电脑”，等待显示已连接。无需填写服务器地址、端口或配对码，也无需安装开发工具。
4. 在账号矩阵选择账号与执行电脑，点击打开小红书，按页面提示登录。登录完成后会自动继续同步，可随时停止。电脑需要已安装受支持的 Chrome 或 Edge。

以后使用时启动连接器并打开工作台即可。连接器窗口保持运行；电脑休眠、断网或关闭窗口后，需要恢复连接才能继续执行任务。正常登录和明确授权始终由成员完成。

## 日常创作与同步

- 发布中心进入图文创作，可按原有设置一次生成 1–12 张图片，也可使用原有素材库和二创功能。切换素材选择后，返回创作页面继续填写。
- 审核通过后，系统自动开始保存草稿。正式发布由成员在小红书完成；电脑草稿不能保证自动出现在手机。
- 停止任务后，等待电脑确认。若显示结果待核对，请在原执行电脑检查，不要连续重新上传。
- 遇到验证码、账号限制或异常登录，先在平台人工核对，再由管理员恢复相应操作。
- 管理员撤销设备后，该设备应从有效设备列表消失；对应账号需要重新连接。撤销不会替成员自动切换到其他电脑。

## 交付人员验收

使用两个独立客户团队、各自的成员账号，分别在真实 Mac 和 Windows 完成首次连接、再次启动、选择本机、平台登录、同步、停止、草稿核对。验证两个客户互不可见，运营权限不能撤销设备或更改模型。记录电脑型号、系统版本、连接器版本和结果；没有实测的电脑不能记为通过。
