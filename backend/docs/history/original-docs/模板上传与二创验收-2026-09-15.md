# 模板上传与二创验收

日期：2026-09-15。公网：https://124.222.193.198/

## 本次交付

- 发布中心默认显示「模板素材库」，顶部提供「上传图片」按钮，空状态另有「选择本地图片」。普通客户管理员与运营可上传，无需平台管理员。
- 本地多图逐张上传，显示每张成功或失败结果；支持中文文件名、PNG/JPG/WebP，单张最多 8 MB、每批最多 30 张。
- 上传成功立即创建当前租户的素材记录，显示缩略图；不要求填写文案、来源链接或等待平台发布审核。
- 支持搜索、分类、预览、最多选择 9 张、单独删除、批量删除。同客户重复上传按文件哈希去重。
- 选择素材后切换到「图文创作」，保留已填写选题。图片有「直接生成图片」「素材二创」两种模式，文案独立生成。
- 素材二创实际发送原图文件到兼容 `/images/edits` 的 GPT Image 服务。返回结果持久归档并回流素材库，创作任务记录来源图片 ID 和强度。
- 原图和二创图存于云端按租户隔离的目录，业务记录存 PostgreSQL。图片读取需要鉴权，执行器使用限定任务的授权下载。

## 原因与修复

1. 原前端没有可用上传控件，且入口受平台管理员权限限制。
2. 原上传没有创建用户可见素材记录，中文文件名也会被旧校验拒绝。
3. 原全局 JSON 限制为 2 MB，后置上传解析器无法提高限制。
4. 原二创调用只发送文字提示，未传原图；模板选择只改选题，未传素材。
5. 之前多次传输将修改放在发行目录根部，未更新 `src/` 与 `server/`，生成的镜像始终相同。
6. 旧全局样式强制显示隐藏文件控件并影响按钮对齐。本次独立约束素材区样式，检查桌面和手机布局。

## 使用与限制

1. 打开发布中心，在模板素材库点击「上传图片」。
2. 勾选上传后的素材，点击「使用所选图片」。
3. 填写独立选题，使用「素材二创」生成图文；不使用参考图时选择「直接生成图片」。
4. 预览和修改后选择账号保存草稿。

二创强度范围是 0.50–0.70，默认 0.60。目前兼容图片编辑接口不支持精确数值强度，系统将其用于提示词中的变化程度指导，并在界面说明；不保证 60% 相似度，不把数值当成接口原生权重。未接入编辑能力的模型会明确报错，不能静默退回无参考图生成。

COS 尚未接入。当前上传空间按租户检查 512 MB 上限；生成归档的统一额度、全局磁盘配额、批量大规模并发、文件生命周期和自动物理回收仍待完善。素材删除先删除业务记录，保留文件以避免破坏已生成任务的图片引用；不能将删除记录等同于立即释放磁盘。平台网页版草稿仍在该账号执行电脑的专属浏览器，手机不会自动同步。
