# 线索与易用性验收

## 四项调整

1. 同步结果中的所有外部评论及收到的私信自动进入线索中心，不依赖“滴滴我”等关键词。排除自己的回复，按客户、账号、来源类型、记录 ID 去重。已收录的历史互动补录，保留跟进记录；主动删除的线索不在重同步时复活。保存首次跟进后变为“跟进中”。
2. 工作台每 3 秒检查轻量线索状态；发现新记录弹出提醒并刷新内容，可以立即进入线索中心。首次加载旧线索只显示待跟进数量；首次补录发生在状态基线之后时会提醒。工作台关闭时不提供系统推送。平台数据必须先由在线且已登录的执行电脑同步到系统，才能收录并提醒；不承诺平台端产生评论的瞬间即已采集。新工作区默认开启事件同步，保留老工作区的开关选择。本机 MOYA 已开启。
3. 配置分为“写文案”“生成图片”，常用服务自动填地址和原有默认模型，只需粘贴密钥。高级地址、接口协议及自定义模型折叠；去除 HTTPS 等技术说明。服务目录按用途过滤，不改变已保存供应商、费用、图片数量及原素材。自定义地址仍接受后端安全校验。开通说明链接仅引导至服务商，不自动调用或收费。
4. 创作卡片、选中按钮和滑条统一黑白灰。桌面任务列表与编辑区高度 560px、各自滚动，窄屏任务区 320px。提示使用中文操作名称，滑条显示“轻度变化 / 适中变化 / 更多变化”，保留原数值范围和默认值。

## 数据库升级

新增 `sql/003-interaction-leads.sql`，由迁移管理账号执行。升级放开私信线索来源，保留评论原有来源约束，再添加涵盖两种来源的账号和消息外键。加入主动删除标记，避免重新采集后重复建线索。没有删除真实内容、账号、素材或跟进历史。新安装的 `postgres-schema.sql` 已包含升级；旧备份恢复后仍需执行 003。
